# Alex Makes Products

Static personal brand site for Alex Sanchez. Source content is based on the supplied CV and LinkedIn export. It is a service-led portfolio in English.

## Local preview

Open `dist/index.html` in a browser, or serve the `dist` directory with a static web server.

## Edit content

Update copy in `dist/index.html` and styles in `dist/styles.css`. The production configuration is in `.openai/hosting.json`.
